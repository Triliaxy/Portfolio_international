# Consignes communes aux agents du projet

Ce fichier est la référence unique pour les agents travaillant sur ce dépôt. Lire ces consignes avant toute modification ; elles s'appliquent à l'ensemble du projet.

- Utiliser uniquement HTML, CSS et JavaScript natifs. Ne pas ajouter de framework, de bibliothèque ou d'outil de compilation sauf demande explicite de l'utilisateur.
- Examiner le style du fichier avant de le modifier. Privilégier les tabulations pour l'indentation du code ajouté ou modifié lorsque le format du fichier le permet ; respecter les conventions locales existantes et conserver les autres choix de formatage.
- Limiter les modifications au besoin demandé et éviter les reformatages sans rapport avec la tâche.
- Écrire un CSS simple : chaque propriété doit avoir une utilité concrète. Éviter les déclarations redondantes et les règles inutilisées.
- Mettre les styles propres à une page ou à un composant dans un fichier CSS portant son nom.
- Éviter les libellés décoratifs et les attributs superflus. Conserver les éléments utiles à l'accessibilité et au fonctionnement.
- Ne pas ajouter de travail de référencement (SEO) : il n'est pas demandé pour ce portfolio.
- Conserver la structure simple de `main.js` lors des modifications de navigation.
